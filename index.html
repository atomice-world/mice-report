⑥ K-MICE (한국관광공사 MICE 정보시스템)

K-MICE 포털(k-mice.visitkorea.or.kr) 메인의 소식·MICE 캘린더·카드뉴스·지식마당은 스크립트 지연 렌더링으로 이번 실행에서 목록을 추출하지 못했습니다. 상단 헤더의 7월 캘린더 위젯으로 이번 달 일정 프레임을 대체 제공합니다. 세션 확보 후 재실행 시 정상 수집됩니다.

⑦ 회원사 나라장터 낙찰현황 (7월 누적)

KBID(kbid.co.kr) 낙찰업체명 검색은 로그인이 필요하여 이번 자동 실행에서 수집하지 못했습니다. KBID 로그인 세션 확보 후 재실행하면 이사사·정회원 51개사의 7월 누적 낙찰현황(수주사·발주기관·용역명·낙찰금액·개찰일)이 채워집니다.

⑧ 3억이하 검토 필요 사전규격 (전체보기 →)

KBID 사전규격 API가 로그인 세션을 요구하여 이번 실행에서 수집하지 못했습니다. 세션 확보 후 재실행 시 배정예산 3억원 이하·등록마감 미도래 용역 사전규격이 키워드 중요도순으로 채워집니다.

⑨ 3억이하 검토 필요 입찰정보 (전체보기 →)

KBID 입찰공고 검색이 로그인 세션을 요구하여 이번 실행에서 수집하지 못했습니다. 세션 확보 후 재실행 시 추정가격 3억원 이하·마감 미도래 입찰정보가 키워드 중요도순으로 채워집니다.
